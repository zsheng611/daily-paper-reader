## 摘要
反射高能电子衍射（RHEED）可提供薄膜生长过程中表面演化的丰富信息，但非自动化的、依赖操作者的对准以及碎片化的分析工作流限制了其在全自主合成中的潜力。在此，我们提出一个开源硬件与软件工具包，使操作者和人工智能（AI）智能体都能使用RHEED控制与定量分析。该工具包在脉冲激光沉积系统上进行了演示，提供可编程电子光学控制、自动束流对准与摇摆曲线采集，以及一种无需训练的晶体学方位角对准方法。Auto RHEED应用通过共享的图形界面和编程接口（包括一个模型上下文协议（MCP）服务器）提取结构与生长相关的可观测量。一个由智能体驱动的演示展示了自然语言请求如何引导定量分析的选择、配置与执行。可扩展的适配器接口简化了随着社区开发的AI分析和RHEED模拟方法不断涌现而对其进行的整合，并由面向AI编码智能体设计的Markdown实现指南提供支持。这些能力支持通过物理测量与学习到的图像表征对表面演化进行互补描述，同时为纳入新的计算方法提供了实用路径。总之，这些工具降低了自动化和智能体化RHEED测量的门槛，并为未来由演化表面引导的薄膜合成智能体控制奠定了基础。

## Abstract
Reflection high-energy electron diffraction (RHEED) provides rich information about evolving surfaces during thin-film growth, but non-automated, operator-dependent alignment and fragmented analysis workflows limit its potential in fully autonomous synthesis. Here, we present an open-source hardware and software toolkit that makes RHEED control and quantitative analysis accessible to operators and artificial intelligence (AI) agents. Demonstrated on a pulsed laser deposition system, the toolkit provides programmable electron-optics control, automated beam alignment and rocking-curve acquisition, and a training-free method for crystallographic azimuthal alignment. The auto RHEED application extracts structural and growth-related observables through shared graphical and programmatic interfaces, including a Model Context Protocol (MCP) server. An agent-driven demonstration shows how natural-language requests can guide the selection, configuration, and execution of quantitative analyses. An extensible adapter interface streamlines the incorporation of community-developed methods for AI analysis and RHEED simulation as they emerge, supported by Markdown implementation guides designed for AI coding agents. These capabilities support complementary descriptions of surface evolution through physical measurements and learned image representations while providing a practical route for incorporating new computational methods. Together, these tools reduce barriers to automated and agentic RHEED measurements and establish a foundation for future agentic control of thin-film synthesis guided by the evolving surface.

## 2. 方法论

### 2.1 FPGA 可编程电子光学控制链
- 硬件：Xilinx Zynq 平台（PYNQ-Z2）实现 FPGA 逻辑；两块 Alameda MAXREFDES24 多通道 DAC 挂载于 PMOD 接口；24 V 供电经 DC/DC 降至 12 V 供 FPGA，5 V 经 DB26 切换电子控制单元至"计算机控制"模式。
- 通道分配：4 路驱动偏转线圈（X1、X2、Y1、Y2），4 路设定电子束参数（发射电流、加速电压、聚焦、栅极）。
- 通信：用户/脚本/AI 智能体通过以太网向 FPGA 上的 HTTP 服务器发指令，可施加任意同步电压序列——这是通用束流操控与自动摇摆曲线校准的前提。

### 2.2 束流居中校准（经验性线圈耦合关系）
- 物理动机：摇摆曲线需在扫掠掠射角 α 时保持束斑落点不变。增大 α 时 X1 将束流推离表面、X2 拉回，二者须标定耦合。测得强度可写为 I(α) ∝ I_diff(α)·G(α)·Φ(α)，其中 G 为几何效应、Φ 为束流通量（大偏转下被光阑切割会变化），故强度变化同时含衍射与非衍射贡献。
- 流程：固定矩形 ROI（216×293 px）跟踪镜面斑，积分亮度为对准信号；X1 取 20 个电压（−2.40 至 −1.43 V），每个 X1 下 X2 扫 171 步、步长 0.01 V；对每条 I–X2 曲线用局部抛物线拟合取亚步精度峰值 X2^max。
- 结果：X2^max 与 X1 呈高度线性，最小二乘拟合 **X2 = −1.8608 X1 − 2.1764（R² = 0.994）**，即束流居中的一阶判据。

### 2.3 免训练的方位角自对称对准
- 定义：晶学方位 φ = φ_lab − φ_0，其中 φ_lab 为电机定义的实验室方位角，φ_0 为待定偏移。
- 几何参考（仅用首帧确定，之后逐帧复用）：
  - 直接束为上半帧最亮连通区（>99.5 百分位），其水平位置定义竖直镜像轴，评分时以半径 +5 px 掩膜屏蔽。
  - 阴影边（样品地平线）用水平边缘 Sobel 算子（先 σ = 3 px 高斯平滑并归一化）检测，沿中心列（|x−x_b| ≤ 150 px）积分得行剖面，束流下方最强峰即边缘行；跨列拟合边缘斜率 m 得到面内倾角 θ = arctan m，并对每帧绕束流做 θ 旋转校正（本例 +1.9°）。
- 预处理：差分高斯（DoG，σ1 = 3、σ2 = 20 px）带通滤波去背景辉光与噪声，再标准化为零均值单位方差。
- 对称性评分：在阴影边以下区域沿镜像轴切分，左半镜像翻转后与右半用 **SSIM**（w×w = 7×7 窗口，C1 = (0.01L)²、C2 = (0.03L)²、L = 1）比较，帧得分 S(φ) = mean SSIM(flip(L), R)，完全对称时为 1。
- 对准：取 S(φ) 最大值，并在离散峰 ±1.5° 内做局部高斯拟合细化。整个约 100 帧扫描仅需数秒。

### 2.4 Auto-RHEED 分析平台
- 架构：Flask 服务器暴露**解耦的 Python 分析核心**（NumPy、SciPy、OpenCV），同时提供浏览器交互界面（HTML5 canvas 叠加、Plotly.js）、API 与 **MCP（Model Context Protocol）服务器**；操作者与智能体调用的是同一实现，仅在参数选择上不同。
- 四阶段流水线：①原始数据摄入（HDF5、.mp4/.avi/.mov、NumPy 数组、单帧文件夹、.img/TIFF）→ ②几何标定 → ③逐帧自动测量 → ④结构化导出（CSV、带 JSON 元数据的标注帧、出版级图）。
- 关键公式与算法：
  - 相对论电子波长 λ = h / √(2m₀eV(1 + eV/2m₀c²))；
  - 小角 RHEED 关系 **d = λL_C / Δx**（Δx 为镜面与一级条纹间距，L_C 为样品–荧光屏距离），单次标定固定像素–倒空间比例；
  - 条纹提取：条带 ROI 逐列求和成一维剖面，非对称最小二乘（Eilers，λ_ALS = 10⁵、p = 0.01；另有滚球、迭代多项式、移动最小值可选）去背景，prominence 检测峰并用抛物线亚像素细化，逐帧以上一帧位置为种子跟踪；
  - 表观面内相干长度 **L = λL_C / (w·s)**（用条纹半高宽 w 替代 Δx）；
  - 生长速率：先减去 EMA 包络去趋势，加 Hann 窗后做离散傅里叶变换，P(f) = |FFT{[I(t) − Î(t)]·w_Hann(t)}|，DC 置零，取主频 f₀ 为 ML/s，绝对沉积速率 **R = f₀ · d_layer**（d_layer 默认 3.905 Å/ML，可手动覆盖）。
- 适配器（adapter）机制：三类——逐帧推理模型、对完整嵌入序列的后处理分析、衍射模拟后端；每个适配器声明带类型的描述符（名称、任务、运行时需求、默认选项），模拟器还可声明输入、能力与 JSON 参数模式，浏览器控件据此自动生成；通过 Python entry points 发现，外部包无需改动核心；重运行时（PyTorch、Transformers、Ultralytics、求解器）仅在运行时加载；每次运行记录输入哈希、设备、锁定包版本与求解器/预处理设置以保溯源。随包分发 4 个适配器：DINOv3 嵌入、RHAAPsody 变点检测、YOLO 实例分割、torch-rheed（Fortran 动力学衍射代码的 PyTorch 移植，可 GPU 执行）。
- 面向 AI 编码智能体的 Markdown 实现指南规定了适配器接口、结果模式、坐标与溯源不变量及验证步骤。

### 2.5 摇摆曲线与角度标定
- 由 FPGA 程序化"摇动"线圈，摇摆视频即一段普通图像序列，掠射角逐帧成为可测量量。
- 逐帧跟踪直接束位置；顶部扫描段因束流被狭缝切割，用正弦拟合补全。阴影边自动定位给出 α = 0，掠射角由小角几何 **α = arctan[(r_edge − r_beam)·s / L]** 给出，其中屏标度 s = 7.358×10⁻³ cm/px（对已知直径 4.98 cm 的荧光屏做 RANSAC 圆拟合，拟合直径 676.8 px），L = 10.5 cm。
