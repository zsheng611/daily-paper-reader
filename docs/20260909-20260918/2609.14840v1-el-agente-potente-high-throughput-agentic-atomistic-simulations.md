## 摘要
基础机器学习原子间势（MLIPs）正在改变原子模拟，其能在广阔化学空间内以一小部分计算成本达到接近从头算（ab initio）的精度。将这些工具用于高通量性质计算的一个核心挑战是，在不损害工作流严谨性的前提下，将高层次的科学意图转化为自适应模拟活动。我们提出 El Agente Potente，这是一个智能体系统，它将类型化执行图与互补的编码模式相结合，用于 MLIPs 驱动的原子模拟。类型化执行图为标准化工作流提供结构化且具备溯源感知的执行，其中大语言模型（LLM）仅限用于规划与路由，而确定性的 Python 组件执行科学计算与验证。作为对这种结构化执行的补充，编码智能体为需要更大流程灵活性的任务构建定制化工作流，同时调用现有的 Potente 函数来执行受支持的计算。我们展示了 El Agente Potente 在计算材料发现、分子能量景观探索、吸附和催化反应工作流中的应用，并系统基准评估了可复现性和 LLM token 成本。这些结果确立了类型化执行图和基于代码的工作流构建作为智能体科学计算的互补机制，将受控、可审计的执行与定制化原子模拟所需的灵活性结合起来。

## Abstract
Foundational machine-learning interatomic potentials (MLIPs) are transforming atomistic simulations by achieving near-ab initio accuracy across large chemical spaces at a fraction of the computational cost. A central challenge in using these tools for high-throughput property calculations is translating high-level scientific intent into adaptive simulation campaigns without compromising workflow rigour. We introduce El Agente Potente, an agentic system that combines typed execution graphs with a complementary coding mode for MLIPs-driven atomistic simulations. Typed execution graphs provide structured and provenance-aware execution for standardized workflows, with large language models (LLMs) restricted to planning and routing while deterministic Python components perform scientific computation and validation. Complementing this structured execution, a coding agent constructs customized workflows for tasks requiring greater procedural flexibility while invoking existing Potente functions for supported calculations. We demonstrate El Agente Potente across computational materials discovery, molecular energy-landscape exploration, adsorption, and catalytic reaction workflows, together with systematic benchmarks of reproducibility and LLM token cost. These results establish typed execution graphs and code-based workflow construction as complementary mechanisms for agentic scientific computing, combining controlled, auditable execution with the flexibility required for customized atomistic simulations

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基础机器学习原子间势（MLIPs）正以远低于从头算（ab initio）的成本，在广阔化学空间内实现接近从头算的精度，从而扩展原子模拟的规模与范围。MACE、MatterSim、Orb、PET-MAD 等模型提供了跨材料与分子体系的通用计算基础设施。
- **核心挑战**：将这些基础 MLIP 用于高通量性质计算，远不止于高效的能量/力评估。实际研究必须协调结构准备、弛豫、采样、性质计算、验证、失败处理和数据聚合，且不同科学问题的工作流差异巨大。
- **现有方案的两难**：
  - 传统高通量框架（AFLOW、AiiDA、Pyiron、Atomate2）基础设施强大，但使用门槛高，需要跨多个模拟软件包的专业知识和领域知识。
  - LLM 科学智能体（LAMMPS-Agent、Masgent、AtomisticSkills 等）能灵活地将高层目标转化为工具调用、工作流决策或生成代码，但更大的运行时灵活性带来新挑战：**科学自主性不能以牺牲可复现性、溯源性和对数值执行的显式控制为代价**。
- **研究定位**：在 El Agente 系列（Gráfico、Seguro、Forjador 等）基础上，El Agente Potente 专门面向 MLIP 驱动的原子模拟，提出将**结构化工作流执行**与**可编程智能体灵活性**相结合的混合设计。

## 2. 方法论：核心思想与关键技术

- **核心设计原则**：分离"智能体科学推理与工作流组合"和"经过验证的数值执行"，使智能体能自适应地编排任务，而无需重新生成既有的计算过程。

- **两种互补执行模式**：
  1. **类型化执行图（Typed Execution Graph）**——面向标准化高通量任务
     - 计算节点包括：结构检索/生成、MLIP 弛豫、可选过滤、下游性质计算、结果聚合。
     - **LLM 仅做受限科学决策**（如依据用户目标与结构元数据选择下游计算），确定性 Python 函数执行底层模拟与数据处理。
     - 图结构机制：**映射操作**将计算扇出到各结构；**流式执行**让下游任务在依赖满足时立即启动；**连接操作**仅在必要时同步结果。
     - 输出、路由与过滤决策、失败、模拟工件、溯源均保存为结构化工作流状态；选定语义溯源可选地持久化到知识图谱。
     - 具体实现（SI）：工具 `run_mlff_workflow` 接收 `MLFFWorkflowRequest`；候选分支（`generate_structures`，支持 cif/xyz/name/smiles/formula/mp_id）与参考分支（`prepare_mp_branch`，从 Materials Project 取竞争相）；两支经 join 同步后由 `filter_by_stability` 按 `e_above_hull_cutoff` 过滤；`route_properties` 由内部 LLM 路由器输出类型化性质节点配置，经判别式联合校验后派发。
     - 派发目标节点：`MLFFMolecularDynamics`、`MLFFIonicConductivity`、`MLFFElasticity`、`MLFFHarmonicPhonon`、`MLFFQHAPhonon`、`MLFFAnharmonicPhonon`、`MLDensityOfStates`、`MLFFWidomInsertion`、`MLFFGCMC`，以及 `relax_failed_result`、`filtered_result`、`relax-only_result` 等终止节点。
     - 每个输入结构都产生类型化输出（即使弛豫失败或被过滤），保证"无静默丢弃"。
     - 聚合后写确定性工件：`output.json`、`property_summary.csv`、相图文件、轨迹、日志、失败快照。
     - **三级并行模型**：候选结构弛豫、参考条目弛豫、每个结构的多性质节点均可并发；物理资源分配（GPU 槽位、计算器复用、线程安全初始化）由运行时控制。
  2. **编码模式（Coding Mode）**——面向需要定制流程逻辑的任务
     - 编码智能体构建任务特定的 Python 工作流，可组合可复用的 Potente 函数、外部生态工具和执行图本身。
     - 关键约束：**当所需计算已被支持时，调用现有 Potente 函数而非重新实现数值过程**。
     - 允许智能体定制控制流、迭代、数据依赖与后处理。

- **分层抽象**：Potente 可在不同抽象层级运行——既调用完整高通量工作流，也在需要更大流程灵活性时组合更底层能力。
